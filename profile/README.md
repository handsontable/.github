## Our products

### [Handsontable DataGrid](https://github.com/handsontable/handsontable)

A JavaScript data grid with an Excel-like editing experience. Use it with JavaScript, TypeScript, React, Angular, or Vue to build apps where users enter, edit, validate, and process data.

```bash
npm install handsontable
```

### [HyperFormula](https://github.com/handsontable/hyperformula)

A headless spreadsheet calculation engine for business web apps. It ships with 400+ formula functions, CRUD operations, undo-redo, clipboard support, and sorting, and runs in the browser or on Node.js.

```bash
npm install hyperformula
```
